# C# design-pattern lessons

From the repository root:

```sh
python3 scripts/run.py 'C#' DesignPatterns/ATMMachineStateDesign
```

Replace the lesson name with any of the 14 names in the [main guide](../../README.md).
The named source files are executable entry points. The implementation file is
`Patterns.cs`.
It contains the actual classes, interfaces, and demo flows; search for the lesson
name to start reading. See the main guide for prerequisites and assumptions.
